# Como executar:
Abra o terminal na pasta raiz do projeto (com o ambiente virtual ativado) e rode:

``Bash
python popular_db.py
```
``Bash
python popular_posts.py
```
``Bash
python popular_retroativo.py
```
Nota importante: Como cada projeto acadêmico costuma nomear os campos dos modelos (Usuario, Post, etc.) de um jeito ligeiramente diferente, caso alguma coluna dê erro por falta de atributo (como o campo tipo ou o método de definir senha), basta verificar o arquivo App_Barbearia/models.py e ajustar os nomes dos campos para corresponder exatamente ao que vocês programaram.
